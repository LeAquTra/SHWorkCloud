# 作业云盘 前端对接指南

> 面向**前端开发**。后端只提供 REST 接口，本文档给出页面怎么接、每个流程怎么实现、以及会踩的坑。
> 逐条接口的完整参数与响应示例见 [`后端接口手册.md`](后端接口手册.md)；设计背景见 [`SHWordCloud_Standard_v2.0.md`](SHWordCloud_Standard_v2.0.md)。

## 1. 五分钟接入

### 1.1 基本信息

| 项 | 值 |
|----|-----|
| 后端地址 | 开发：`http://localhost:8081/api`（或由 Vite proxy 转发 `/api`）；生产：Nginx 同源反代 `/api` |
| 鉴权 | 请求头 `Authorization: <token>`，**不加 `Bearer` 前缀** |
| 返回体 | `{ code, message, data }`；`code === 0` 为成功 |
| HTTP 状态 | 业务错误一律 **200**；只有未登录 → **401**、无权限 → **403** |
| 分页 | `page` 从 **1** 开始；返回 `{ page, size, total, records }` |

### 1.2 建议的请求封装

```ts
// api/http.ts
import axios from 'axios'

const TOKEN_KEY = 'sc_token'
// 机房是共用电脑：用 sessionStorage，关掉标签页即失效。
// 用 localStorage 会让下一位同学打开浏览器直接进上一位的网盘。
export const getToken = () => sessionStorage.getItem(TOKEN_KEY) || ''
export const setToken = (t: string) => sessionStorage.setItem(TOKEN_KEY, t)
export const clearToken = () => sessionStorage.removeItem(TOKEN_KEY)

export class ApiError extends Error {
  constructor(public code: number, message: string) { super(message) }
}

const instance = axios.create({ baseURL: '/api', timeout: 60000 })

instance.interceptors.request.use((cfg) => {
  const token = getToken()
  if (token) cfg.headers.set('Authorization', token)
  return cfg
})

function toLogin(hint: string) {
  clearToken(); sessionStorage.clear()
  if (!location.pathname.startsWith('/login')) location.assign('/login')
  console.warn(hint)
}

async function request<T>(cfg): Promise<T> {
  const { data: body } = await instance.request<{ code: number; message: string; data: T }>(cfg)
  switch (body.code) {
    case 0: return body.data
    case 40100: toLogin('未登录或会话已失效'); throw new ApiError(body.code, body.message)
    case 40117: toLogin('账号已被禁用'); throw new ApiError(body.code, '账号已被禁用，请联系老师')
    case 40119:                                  // 首登强制改密
      if (!location.pathname.startsWith('/change-password')) location.assign('/change-password')
      throw new ApiError(body.code, body.message)
    default: throw new ApiError(body.code, body.message || '请求失败')
  }
}

export const get = <T>(url: string, params?: object) => request<T>({ url, method: 'GET', params })
export const post = <T>(url: string, data?: unknown, cfg = {}) => request<T>({ url, method: 'POST', data, ...cfg })
export const put = <T>(url: string, data?: unknown) => request<T>({ url, method: 'PUT', data })
export const del = <T>(url: string, data?: unknown, params?: object) =>
  request<T>({ url, method: 'DELETE', data, params })
```

### 1.3 会话与空闲登出

- 登录成功后 `setToken(data.token)`，并把 `mustChangePassword` 存下来；
- **路由守卫**：无 token → `/login`；`mustChangePassword` → 强制留在 `/change-password`；
- **空闲自动登出**：后端 30 分钟无操作失效（`sa-token.active-timeout`），前端建议在 **20 分钟**时弹"即将退出"提醒，
  60 秒后调 `POST /auth/logout` 并跳登录页。这能避免学生填了半天表单突然 401；
- **离开页面拦截**：上传队列里有未完成任务时 `beforeunload` 弹确认 —— 学生下课前最容易漏掉这一步。

## 2. 核心概念：viewType（决定了怎么渲染）

文件列表里每个文件都带 `viewType`，前端**按它分流即可，不要自己写后缀白名单**：

| viewType | 渲染 | 接口 |
|----------|------|------|
| `image` | `<img>` / `el-image` | `preview-url`（签名）或 `GET /files/{id}/preview` |
| `pdf` | 浏览器 PDF 阅读器 / pdf.js | 同上（支持 Range，可跳页） |
| `video` | `<video>` | 同上（支持 Range，可拖进度条） |
| `audio` | `<audio>` | 同上（支持 Range） |
| `text` | 代码/文本查看器 | `GET /files/{id}/text` |
| `office` | 文本视图（doc/docx/pptx 提取正文） | `GET /files/{id}/text` |
| `none` | 不预览，只给"下载" | `download-url` |

```ts
function renderKind(item: FileItemVO) {
  switch (item.viewType) {
    case 'image': return 'img'
    case 'pdf':   return 'pdf'
    case 'video': return 'video'
    case 'audio': return 'audio'
    case 'text':
    case 'office': return 'text'
    default: return 'downloadOnly'
  }
}
```

## 3. 六个关键流程

### 3.1 登录 / 首次改密

```ts
// 登录页
const cfg = await get<RegisterConfigVO>('/auth/register-config')   // 公开接口，先问清楚流程
showRegisterEntry.value = cfg.registerEnabled                      // 不开放就别显示注册入口

const login = await post<LoginVO>('/auth/login', { login: 学号, password: 密码 })
setToken(login.token)
router.replace(login.mustChangePassword ? '/change-password' : '/')
```

```ts
// 改密（首登强制走这里）
await post('/auth/password', { oldPassword, newPassword, confirmPassword })
router.replace('/')
```

> 密码规则与后端一致：8~32 位、必须同时含字母和数字、不能有空格、不能与学号相同。
> 前端最好本地先校验一次，别等提交后才报错。

### 3.2 注册（可选通道）

```ts
const cfg = await get<RegisterConfigVO>('/auth/register-config')

// 只有 requireImageCaptcha=true 时才需要这两步
if (cfg.requireImageCaptcha) {
  const cap = await post<CaptchaVO>('/auth/captcha', {})   // { captchaId, type, imageUrl, prompts }
  // type: 1 字符输入 / 2 单选 / 3 点选（clicks 要换算回原图像素）
  const { captchaPassToken } = await post<{ captchaPassToken: string }>('/auth/captcha/verify', {
    captchaId: cap.captchaId, answer, clicks,
  })
  passToken = captchaPassToken
}

await post('/auth/email-code', { email, captchaPassToken: passToken })   // 发邮件验证码
await post('/auth/register', { email, emailCode, password })             // 注册
```

⚠️ 注册提交**不需要**带 `captchaPassToken`（它已在发邮件码时被一次性消费）。

### 3.3 上传（最复杂的一块）

```ts
// ① 先查容量，空间不够就别开始传
const quota = await get<QuotaVO>('/user/quota')
if (file.size > quota.free) {
  // 提示并给"清空回收站"入口：回收站占用在 quota.recycleUsed
  return
}

// ② 算文件指纹（大文件用抽样指纹，避免为秒传先算几十秒哈希）
//    ⚠️ 不要用 crypto.subtle / crypto.randomUUID：内网 http 不是安全上下文，这些 API 不存在
const fingerprint = await computeFingerprintInWorker(file)

// ③ 试秒传；hit=false 表示未命中，继续正常上传
const instant = await post<CommitVO>('/files/instant-upload', {
  md5: fingerprint, parentId, name: file.name, size: file.size, contentType: file.type,
})
if (instant.hit) { refreshList(); return }

// ④ 申请上传凭证（ObjectKey 由服务端签发，前端不要自己拼 key）
const ticket = await post<UploadTicketVO>('/oss/ticket', {
  name: file.name, size: file.size, contentType: file.type,
})

if (ticket.partCount <= 1) {
  // ⑤a 小文件：单次 PUT
  const put = await post<PutUrlVO>('/oss/put-url', {
    uploadToken: ticket.uploadToken, contentType: file.type,
  })
  // ⚠️ Content-Type 必须用响应里返回的 contentType，否则 OSS 报 SignatureDoesNotMatch
  await xhrPut(put.url, file, put.contentType, (percent) => progress.value = percent)
} else {
  // ⑤b 大文件：分片
  const { uploadId } = await post<{ uploadId: string }>('/oss/multipart/init', {
    uploadToken: ticket.uploadToken, contentType: file.type,
  })
  const partNumbers = Array.from({ length: ticket.partCount }, (_, i) => i + 1)
  const { contentType, urls } = await post<PartUrlsVO>('/oss/multipart/part-urls', {
    uploadToken: ticket.uploadToken, uploadId, partNumbers,   // 单次最多 500 个
  })
  const etags = await uploadPartsWithConcurrency(file, ticket.partSize, urls, contentType, 2)
  await post('/oss/multipart/complete', { uploadToken: ticket.uploadToken, uploadId, parts: etags })
}

// ⑥ 建立索引（这一步成功才算"保存到网盘"）
const commit = await post<CommitVO>('/files/commit', {
  uploadToken: ticket.uploadToken, parentId, name: file.name, contentType: file.type, md5: fingerprint,
})
// commit.receipt 是提交凭证，界面上要显示出来给学生核对
```

**必须做对的三件事**

1. **`Content-Type` 用响应里返回的那个值**：OSS V1 签名把 `Content-Type` 计入待签字符串，
   自己随便设会导致 `SignatureDoesNotMatch`；
2. **`ETag` 要去掉双引号**再提交给 `complete`（OSS 返回 `"abc"`，提交要 `abc`）；
3. **两阶段进度**：`上传中`（OSS 直传）与`正在登记`（`/files/commit`）必须分开显示。
   OSS 传完 ≠ 保存成功，只显示到 100% 会让学生以为存好了 —— 下课前关机就丢了。

**断点续传**：把 `{ uploadToken, uploadId, partSize, parts }` 存起来（key 里带 userId）。
刷新页面后重新选择同一文件，先调 `GET /oss/multipart/parts?uploadToken=&uploadId=`
拿回服务端已收到的分片，跳过它们继续传 —— 这比 SDK 的内存 checkpoint 可靠。

**暂停 vs 取消**：暂停只 abort 请求、保留断点；取消要调 `POST /oss/multipart/abort`
让服务端清掉未完成分片（否则 OSS 会持续计费）。

### 3.4 在线阅览

```ts
// 图片 / PDF / 视频 / 音频
async function openStreamable(item: FileItemVO) {
  const { url } = await get<{ url: string }>(`/files/${item.id}/preview-url`)   // 10 分钟签名
  if (item.viewType === 'image') return `<img src="${url}">`
  if (item.viewType === 'pdf')   return `<iframe src="${url}">`
  if (item.viewType === 'video') return `<video src="${url}" controls>`
  return `<audio src="${url}" controls>`
}

// 文本 / Office
async function openText(item: FileItemVO) {
  const data = await get<TextContentVO>(`/files/${item.id}/text`)
  // data.charset 会告诉你后端用了哪种编码（UTF-8 / GBK）
  // data.truncated 为 true 时提示"内容过长已截断，请下载查看完整文件"
  // data.hint 有值时要显示（例如"已提取纯文本，排版会丢失"）
  return data.content
}
```

**为什么图片/视频优先用签名地址**：浏览器的 `<img>` / `<video>` **无法携带 `Authorization` 头**。
签名地址是自包含的（有效期写在 URL 里），可以直接放进 `src`。

### 3.6 头像

```vue
<input type="file" accept="image/jpeg,image/png" @change="onPick" />
```

```ts
async function onPick(e: Event) {
  const file = (e.target as HTMLInputElement).files?.[0]
  if (!file) return
  // 前端先挡一道，给出即时反馈（后端仍会独立校验）
  if (!/^image\/(jpeg|png)$/.test(file.type)) return message.error('只支持 JPG / PNG')
  if (file.size > 5 * 1024 * 1024) return message.error('头像不能超过 5MB')

  const form = new FormData()
  form.append('file', file)
  const profile = await post<UserProfileVO>('/user/avatar', form)   // 返回最新资料
  // profile.avatarUrl 是 1 小时签名地址，可直接给 <img src>
  // profile.avatarVersion 变了就说明换了头像，用它做缓存失效
}

// 清除头像（同时删掉 OSS 对象）
await del<UserProfileVO>('/user/avatar')
```

> 后端会校验 magic bytes 并真正解析图片，**只看后缀是不够的** —— 前端也用不着自己解析。

## 6. 联调与自测

后端提供了端到端验收脚本，**不需要前端就能验证后端是否正常**：

```powershell
pwsh ./scripts/api-smoke.ps1 -Login admin -Password 'YourInitPassword'
```

它会跑：登录 → 个性属性 → 头像上传/读回/更换/清除 → 上传（含 OSS 直传与 commit）→
下载回本地并逐字节比对 MD5 → Range 断点续传 → 回收站。前端联调出问题时，
先跑一遍这个脚本，能立刻区分是"后端坏了"还是"前端调用姿势不对"。

## 7. 常见坑清单

| 现象 | 原因 / 解法 |
|------|------------|
| 请求全部 40100 | 请求头字段名必须是 `Authorization`，值是**原始 token**，不加 `Bearer` |
| `<img src>` 图片裂开 | 用了需要鉴权的流式地址。改用 `avatarUrl` / `preview-url` 返回的**签名地址** |
| PUT OSS 报 `SignatureDoesNotMatch` | `Content-Type` 与预签名时不一致 —— 用 `/oss/put-url` 与 `/oss/multipart/part-urls` 响应里返回的 `contentType` |
| 上传 100% 但文件不见了 | 只做了直传、没调 `/files/commit`。commit 成功才算保存 |
| 分片上传报参数错误 | `complete` 的 `parts` 必须按 `partNumber` **升序**，且 `etag` 要去掉双引号 |
| 大文件传到一半失败 | `uploadToken` 有效期 2 小时；超时要重新走 `/oss/ticket`（会换 ObjectKey，已传分片作废） |
| 视频拖不了进度条 | 用了签名地址但 OSS 的 CORS 没暴露 `Range`/`ETag` 头，或用了不支持 Range 的接口。`/files/{id}/preview` 支持 Range |
| 文本乱码 | 用 `/files/{id}/text` 而不是自己 fetch 原始字节 —— 后端会处理 GBK / BOM |
| 中文文件名下载后变 `download.docx` | 说明浏览器没解析 `filename*`；后端已同时给 ASCII 回退名，正常浏览器会用 UTF-8 名 |
| 图片/头像换成新的但界面还是旧的 | 用 `avatarVersion` / 换签名地址做缓存失效 |
| 分页第一页是空的 | `page` 从 **1** 开始，不是 0 |
| 搜索不到文件 | `keyword` 是**前缀匹配**，界面文案改成"输入开头几个字" |
| 回收站清空了容量没变 | 容量是缓存值；等每日对账，或超管调 `POST /admin/ops/reconcile-storage` |
| 内网 http 下 `crypto.randomUUID is not a function` | 非安全上下文没有 Web Crypto。用后端签发的 `uploadKey`，本地 ID 自己用随机字符串生成 |

## 8. 后端尚未提供 / 需要约定的事项

| 项 | 说明 |
|----|------|
| 缩略图 | 图片列表返回原图签名地址，前端用 `el-image` 的 `lazy` + 固定网格自行缩放；后端未生成缩略图 |
| 图片宽高 | 列表不返回宽高（避免为每张图额外读 OSS）；前端可用图片 `onload` 后取 `naturalWidth/Height` 做瀑布流 |
| Word/PPT 完整版面 | 只提供**纯文本提取**（`/files/{id}/text`）。要还原排版需引入 OnlyOffice/LibreOffice 转换，不在本期范围 |
| 旧版 `.ppt` | 二进制格式没有可靠的无依赖解析方案，`viewType=none`，只能下载（`.doc` 已支持，见上） |
| xlsx 表格 | 未实现结构化读取（`viewType=none`）；如需在线看表格请提需求 |
| 打包下载 | 未实现；批量下载请逐个调 `download-url` |
| 预置演示数据 | 无。测试账号请用名单导入接口建，或直接改 `app.register.enabled` 后自助注册 |
